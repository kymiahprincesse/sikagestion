                    GUIDE DE NETTOYAGE - JOURNAL DE CAISSE
                    SIKA GESTION - Suppression des données fictives
═══════════════════════════════════════════════════════════════════════════════

📋 OBJECTIF
─────────────────────────────────────────────────────────────────────────────
Supprimer toutes les données fictives/démo du Journal de Caisse et s'assurer
que le système est complètement synchronisé avec Supabase.

🗑️ ÉTAPES DE NETTOYAGE
─────────────────────────────────────────────────────────────────────────────

1️⃣ NETTOYAGE COMPLET (Supprimer toutes les données)
   Commande:
   node scripts/cleanup-journal-complet.mjs

   Actions effectuées:
   ✅ Suppression de tous les mouvements de caisse
   ✅ Réinitialisation des références dans les dépenses
   ✅ Réinitialisation des références dans les achats
   ✅ Suppression des écritures comptables
   ✅ Préservation des encaissements (données réelles)

2️⃣ SYNCHRONISATION DES ENCAISSEMENTS (Créer les entrées journal)
   Commande:
   node scripts/sync-encaissements-to-journal.mjs

   Actions effectuées:
   ✅ Création des mouvements d'ENTRÉE pour chaque encaissement
   ✅ Liaison encaissement ↔ mouvement_caisse
   ✅ Évitement des doublons (vérifie avant création)

🔄 SYNCHRONISATION AUTOMATIQUE
─────────────────────────────────────────────────────────────────────────────

Le système est maintenant configuré pour synchroniser automatiquement:

┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   DÉPENSES      │────▶│                  │     │                 │
│   (SORTIES)     │     │   JOURNAL DE     │◄────│  ENCAISSEMENTS  │
└─────────────────┘     │   CAISSE         │     │  (ENTRÉES)      │
                        │                  │     │                 │
┌─────────────────┐     │  (mouvements_    │     │  Auto-sync      │
│   ACHATS        │────▶│   caisse)        │◄────│  activée ✓      │
│   (SORTIES)     │     │                  │     │                 │
└─────────────────┘     └──────────────────┘     └─────────────────┘
       │                        │
       │ Manuel                 │ Auto (nouveau)
       │ (bouton "Journal")      │

📊 TABLES CONCERNÉES
─────────────────────────────────────────────────────────────────────────────

• mouvements_caisse    : Journal de caisse (entrées/sorties)
• ecritures_journal    : Journal comptable (écritures)
• depenses            : Dépenses avec mouvement_caisse_id
• achats              : Achats avec mouvement_caisse_id
• encaissements       : Encaissements avec mouvement_caisse_id (NOUVEAU)

🎯 FLUX DE DONNÉES
─────────────────────────────────────────────────────────────────────────────

1. DÉPENSE → JOURNAL (manuel)
   - Créer une dépense
   - Cliquer sur "📖 Enregistrer Journal"
   - Crée une SORTIE dans mouvements_caisse

2. ACHAT → JOURNAL (manuel)
   - Créer un achat
   - Cliquer sur "📖 Enregistrer Journal"
   - Crée une SORTIE dans mouvements_caisse

3. ENCAISSEMENT → JOURNAL (automatique ✓)
   - Créer un encaissement
   - Crée automatiquement une ENTRÉE dans mouvements_caisse
   - Met à jour mouvement_caisse_id

✅ VÉRIFICATION
─────────────────────────────────────────────────────────────────────────────

Après nettoyage, vérifiez dans l'interface:

1. Journal de Caisse (/journal)
   - Plus de données fictives
   - Seuls les encaissements réels apparaissent

2. Encaissements (/encaissements)
   - Colonne "JOURNAL" affiche ✓ Synchronisé

3. Dépenses (/depenses)
   - Les anciennes dépenses sont déliées (pas de ✓ Journal)

4. Achats (/achats)
   - Les anciens achats sont déliés (pas de ✓ Journal)

🚨 PRÉCAUTIONS
────────────────────────────────────────────────════════════════════════════─

⚠️  Le nettoyage est IRRÉVERSIBLE - Toutes les données de journal seront perdues
⚠️  Sauvegardez votre base de données avant de procéder
⚠️  Les encaissements ne sont PAS supprimés (données réelles)

🔧 COMMANDES RÉSUMÉES
─────────────────────────────────────────────────────────────────────────────

# 1. Nettoyer tout le journal
node scripts/cleanup-journal-complet.mjs

# 2. Synchroniser les encaissements existants
node scripts/sync-encaissements-to-journal.mjs

# 3. Les deux commandes ensemble
cd scripts && node cleanup-journal-complet.mjs && node sync-encaissements-to-journal.mjs
