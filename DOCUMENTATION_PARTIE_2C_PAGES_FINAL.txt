### 12.5.1 ÉTAPES D'IMPORTATION

**Étape 1 - Sélection fichier** :
| Élément | Description |
|---------|-------------|
| Type fichier | .xlsx (Excel) uniquement |
| Bouton | "Choisir un fichier Excel" |
| Icône | Upload |
| Couleur | #E8610A |
| Validation | Extension .xlsx obligatoire |

**Étape 2 - Sélection feuille** :
| Élément | Description |
|---------|-------------|
| Type | Select dropdown |
| Options | Liste des feuilles du fichier Excel |
| Détection auto | Oui, lecture des noms de feuilles |
| Affichage | Nom feuille + nombre de lignes |

**Étape 3 - Mapping colonnes** :
| Élément | Description |
|---------|-------------|
| Interface | Tableau de correspondance |
| Colonne gauche | Colonnes du fichier Excel (A, B, C...) |
| Colonne droite | Champs de la base de données |
| Type | Select pour chaque colonne |
| Auto-détection | Tentative de mapping automatique par nom |

**Étape 4 - Prévisualisation** :
| Élément | Description |
|---------|-------------|
| Affichage | Tableau avec 5 premières lignes |
| Colonnes | Toutes les colonnes mappées |
| Validation | Vérification types de données |
| Erreurs | Affichage en rouge si problème |

**Étape 5 - Mode d'import** :
| Mode | Description | Icône | Couleur |
|------|-------------|-------|---------|
| **Fusion** | Ajoute aux données existantes | Plus | #1A7A4A |
| **Remplacement** | Supprime et remplace toutes les données | RefreshCw | #C0392B |

**Étape 6 - Confirmation et import** :
| Élément | Description |
|---------|-------------|
| Bouton | "Lancer l'import" |
| Couleur | #1A7A4A (vert) |
| Confirmation | Modal si mode "Remplacement" |
| Progression | Barre de progression animée |

### 12.5.2 TRAITEMENT IMPORT

#### 12.5.2.1 LECTURE FICHIER
| Étape | Technologie | Description |
|-------|-------------|-------------|
| Upload | FileReader API | Lecture fichier en ArrayBuffer |
| Parsing | XLSX library | Conversion en JSON |
| Extraction | SheetJS | Récupération données par feuille |

#### 12.5.2.2 CONVERSION DONNÉES
| Type | Conversion |
|------|------------|
| **Dates Excel** | Conversion nombre Excel vers Date JS |
| **JSON** | Parsing champs lignes (tableaux) |
| **Nombres** | Conversion string vers number |
| **Booléens** | Conversion "true"/"false" vers boolean |

#### 12.5.2.3 VALIDATION
| Règle | Action |
|-------|--------|
| Champ obligatoire manquant | Erreur ligne X |
| Type incorrect | Erreur ligne X |
| Valeur hors limites | Erreur ligne X |
| Doublon ID | Génération nouvel ID |

#### 12.5.2.4 INSERTION DONNÉES
| Mode | Action |
|------|--------|
| **Fusion** | Appel méthode add du store pour chaque ligne |
| **Remplacement** | Vide store puis appel méthode add |
