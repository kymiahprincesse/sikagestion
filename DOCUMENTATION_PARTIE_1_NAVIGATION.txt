═══════════════════════════════════════════════════════════════════════════════

### 1.1 IDENTITÉ
- **Nom commercial** : SIKA INDUSTRIE
- **Nom technique** : SIKAGESTION
- **Type** : Application web ERP/CRM (Enterprise Resource Planning / Customer Relationship Management)
- **Framework** : React 19.2.6 avec Vite 8.0.12
- **Routing** : React Router DOM 7.16.0
- **State Management** : Zustand 5.0.14
- **Backend** : Supabase (@supabase/supabase-js 2.106.2)

### 4.3 GESTION DE SESSION

| Paramètre | Valeur | Description |
|-----------|--------|-------------|
| **Timeout inactivité** | 30 minutes | Déconnexion automatique après 30 min sans activité |
| **Stockage** | localStorage | Clé: 'sika_auth' |
| **Persistance** | Oui | Session persiste après fermeture navigateur |
| **Vérification** | À chaque action | Mise à jour timestamp dernière activité |

### 4.4 REDIRECTION APRÈS CONNEXION
- **Succès** : Redirection vers `/dashboard`
- **Échec** : Message d'erreur affiché sur la page login
- **Non authentifié** : Toute tentative d'accès à une page protégée redirige vers `/login`
