📍 ACCÈS AU MODULE
──────────────────
Navigation : Sidebar > 🚀 Pilotage Projets
URL : /planification


🎯 FONCTIONNALITÉS PRINCIPALES
────────────────────────────────

1. SÉLECTEUR CLIENTS
   - Boutons rapides : GMCI, AMCC, LDC
   - Dropdown pour tous les clients actifs
   - Filtre automatique de tous les tableaux et graphiques

2. GESTION DES PROJETS
   Actions disponibles :
   ➕ Nouveau Projet
   📝 Modifier
   👁 Visualiser
   🖨 Imprimer
   🗑 Supprimer
   📤 Import Planning (Excel)

3. IMPORT PLANNING INTELLIGENT
   Formats supportés : Excel (.xlsx, .xls)
   
   Processus en 4 étapes :
   - Étape 1 : Upload fichier (drag & drop ou clic)
   - Étape 2 : Prévisualisation et mapping colonnes
   - Étape 3 : Validation mapping
   - Étape 4 : Import et création tâches
   
   Colonnes auto-détectées :
   - Date début/fin
   - Nom tâche
   - Client/Projet
   - Nb techniciens
   - Durée jours
   - Distance site
   - Nb déplacements

4. VUE LISTE PROJETS
   Colonnes affichées :
   - Nom projet
   - Client (badge orange)
   - Dates début/fin
   - Budget prévu
   - Coût réel
   - Écart (vert si économie, rouge si dépassement)
   - % Consommé avec indicateur couleur
   - Statut (badge)
   
   Indicateurs budgétaires :
   🟢 Économe    : < 60% budget consommé
   🟡 Alerte     : 60% ≤ consommé < 80%
   🔴 Dépassement: ≥ 80% budget

5. VUE DÉTAIL PROJET
   
   En-tête :
   - Nom projet et client
   - 4 cartes KPI : Budget Total, Coût Réel, Écart, % Consommation
   - Barre de progression budget (couleur dynamique)
   
   Onglet TÂCHES :
   - Liste complète des tâches
   - Colonnes : Tâche, Dates, Durée, Techniciens, Budgets détaillés
   - Actions : Modifier, Supprimer
   - Bouton "Nouvelle tâche"
   
   Onglet SUIVI BUDGÉTAIRE :
   - Graphique Recharts (barres groupées)
   - Budget Prévu (navy) vs Coût Réel (orange)
   - Ligne écart (rouge pointillée)

6. FORMULAIRE TÂCHE
   
   Champs obligatoires :
   - Nom de la tâche
   
   Champs optionnels :
   - Dates début/fin (calcul auto durée)
   - Nb techniciens (défaut: 1)
   - Distance site (km)
   - Nb déplacements
   - Budget matériel
   - Budget sous-traitance
   - Notes
   - Statut
   
   CALCULS EN TEMPS RÉEL :
   Affichage automatique pendant la saisie :
   - Budget Carburant = (km × 2 × nbDéplacements / 100) × conso × prix
   - Budget Nourriture = nbTech × duréeJours × indemniteRepas
   - Budget Logistique = matériel + sous-traitance
   - Coût Hebdo estimé
   - COÛT TOTAL ESTIMÉ (en grand, orange)
   
   Tous les taux proviennent de useParametresStore (modifiables)

7. SYSTÈME D'ALERTES 80% BUDGET
   
   Déclenchement automatique si :
   - Coût réel ≥ 80% du budget prévu (seuil configurable)
   
   Actions automatiques :
   ✓ Alerte dans Dashboard (section Alertes)
   ✓ Notification push dans NotificationsPanel
   ✓ Badge rouge sur "🚀 Pilotage Projets" (sidebar)
   ✓ Log dans useAuditStore
   
   Niveaux d'alerte :
   - ALERTE    : 80% ≤ consommé < 90%
   - URGENT    : 90% ≤ consommé < 100%
   - CRITIQUE  : consommé ≥ 100%

8. EXPORTS
   
   📊 Export Excel :
   - Feuille 1 : Liste projets avec budgets
   - Feuille 2 : Détail tâches (si projet sélectionné)
   - Nom fichier : Planification_YYYY-MM-DD.xlsx
   
   📄 Export PDF :
   - En-tête SIKA INDUSTRIE
   - Infos projet et client
   - Budgets et écarts
   - Tableau tâches avec autoTable
   - Nom fichier : Planification_YYYY-MM-DD.pdf
   
   🖨 Impression :
   - CSS @media print optimisé
   - Masquage sidebar, header, boutons
   - Ajustement automatique largeur


💾 PERSISTANCE & AUDIT
───────────────────────

Store : usePlanificationStore
Clé localStorage : 'sika_planification'

Structure données :
{
  projets: [{
    id, nom, clientId, devisId,
    dateDebut, dateFin, budgetPrevu,
    statut, referenceProjet, notes,
    creePar, dateCreation
  }],
  taches: [{
    id, projetId, nom,
    dateDebut, dateFin, dureeJours,
    nbTechniciens, kmSite, nbDeplacements,
    budgetMateriel, budgetSousTraitance,
    budgetCarburant, budgetNourriture,
    budgetLogistique, coutHebdo, coutTotal,
    coutReel, statut, notes
  }],
  seuilAlerteBudget: 0.8
}

Audit automatique :
- CREATE projet → module: PLANIFICATION, action: CREATE
- UPDATE projet → module: PLANIFICATION, action: PLANNING_UPDATE
- DELETE projet → module: PLANIFICATION, action: DELETE
- Alerte budget → module: PLANIFICATION, action: ALERTE_BUDGET

🔗 INTÉGRATIONS
────────────────

1. useParametresStore
   Lecture des taux pour calculs :
   - indemniteRepas (FCFA/jour/technicien)
   - prixCarburant (FCFA/litre)
   - consommationMoyenne (L/100km)

2. useDevisStore
   Récupération budget prévu depuis devis lié

3. useCaisseStore
   Récupération coût réel via référence projet
   Filtre : type='SORTIE' && referenceProjet=XXX

4. useClientsStore
   Liste clients actifs pour sélecteur

5. useNotificationsStore
   Notifications alertes budget

6. useAuditStore
   Traçabilité complète des actions

⚙️ CONFIGURATION
─────────────────

Seuil alerte budget (défaut 80%) :
usePlanificationStore.setSeuilAlerteBudget(0.8)

Vérification manuelle alertes :
usePlanificationStore.verifierToutesAlertes()


🚀 DÉMARRAGE RAPIDE
────────────────────

1. Accéder au module : Sidebar > 🚀 Pilotage Projets
2. Sélectionner un client (ex: GMCI)
3. Cliquer "➕ Nouveau Projet"
4. Remplir formulaire projet
5. Dans la vue détail, cliquer "➕ Nouvelle tâche"
6. Saisir tâche et observer calculs temps réel
7. Enregistrer
8. Consulter onglet "Suivi Budgétaire" pour graphique
