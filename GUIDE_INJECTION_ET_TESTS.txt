🌐 MÉTHODE 1: Via l'interface web (RECOMMANDÉE)
   
   1. Ouvrez votre navigateur
   2. Accédez à: http://localhost:5187/injection-donnees
   3. Cliquez sur le bouton "✨ Injecter les données"
   4. Attendez le rapport de confirmation
   
   Cela va injecter:

   - 3 Appels d'offres (différents statuts)

💻 MÉTHODE 2: Via script Node.js (si l'interface ne fonctionne pas)
   
   Créer un fichier inject-devis-factures.mjs et exécuter:
   node inject-devis-factures.mjs
