📥 ONGLET 1 : IMPORT
═══════════════════════════════════════════════════════════════════════════

✅ FONCTIONNALITÉS IMPLÉMENTÉES :

1️⃣ UPLOAD FICHIER EXCEL
   • Formats supportés : .xlsx, .xlsm
   • Bouton "Choisir un fichier" avec icône Upload
   • Affichage du nom du fichier sélectionné

2️⃣ DÉTECTION AUTOMATIQUE DES FEUILLES
   • Liste déroulante des 10 feuilles détectées
   • Icône ChevronDown pour UX améliorée
   • Feuilles reconnues :
     - Clients
     - Fournisseurs
     - Devis
     - Factures
     - Encaissements
     - AO (Appels d'Offres)
     - Caisse
     - Journal (Journal_de_caisse.xlsm)
     - Planification

3️⃣ MAPPING AUTOMATIQUE DES COLONNES
   • Détection intelligente : colonnes Excel → champs store
   • Tableau de mapping avec :
     - Colonne Excel (nom original)
     - Champ cible (auto-détecté ou "Non mappé")
   • Badges colorés :
     - Orange clair : mappé avec succès
     - Navy clair : non mappé

4️⃣ PRÉVISUALISATION 5 PREMIÈRES LIGNES
   • Tableau formaté avec en-tête navy
   • Lignes alternées (blanc / navy clair)
   • Affichage de toutes les colonnes
   • Permet de vérifier avant import

5️⃣ OPTIONS D'IMPORT
   • Radio buttons avec 2 modes :
     ✓ Fusionner : Ajoute aux données existantes
     ✓ Remplacer tout : Efface et remplace

6️⃣ CONVERSION DATES EXCEL
   • Formule : new Date((excelDate - 25569) * 86400000)
   • Exemple : 44621 → 2026-01-15
   • Détection auto des champs "date"

7️⃣ RAPPORT D'IMPORT DÉTAILLÉ
   • Badge vert (succès) ou rouge (erreurs)
   • Nombre de lignes importées
   • Liste des erreurs (max 5 affichées)
   • Message "... et X autres erreurs" si > 5

8️⃣ GÉNÉRATEUR DE FICHIER D'EXEMPLE
   • Bouton "Télécharger le fichier d'exemple"
   • Génère LES_FICHIERS_POUR_LOGICIEL_2026_EXEMPLE.xlsx
   • Contient 9 feuilles pré-remplies avec données réalistes
   • Parfait pour tester l'import immédiatement

🎯 UTILISATION
═══════════════════════════════════════════════════════════════════════════

IMPORT :
1. Cliquer sur "Télécharger le fichier d'exemple" pour obtenir un modèle
2. Ou préparer votre propre fichier Excel avec les colonnes appropriées
3. Cliquer "Choisir un fichier" et sélectionner le .xlsx/.xlsm
4. Sélectionner la feuille à importer dans la liste déroulante
5. Vérifier le mapping automatique des colonnes
6. Consulter la prévisualisation des 5 premières lignes
7. Choisir "Fusionner" ou "Remplacer tout"
8. Cliquer "Lancer l'import"
9. Consulter le rapport d'import

EXPORT :
1. Sélectionner le module à exporter
2. Choisir le format (Excel ou PDF)
3. (Optionnel) Définir une période
4. (Optionnel) Filtrer par client
5. Cliquer "Exporter en Excel" ou "Exporter en PDF"
6. Le fichier est téléchargé automatiquement
